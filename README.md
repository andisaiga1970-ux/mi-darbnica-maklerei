# MI darbnīca mākleriem

Pārlūkā darbināma darba lapa Lielbritānijas nekustamo īpašumu mākleriem ar diviem neatkarīgiem rīkiem.

- `index.html` paliek esošais AI Property Workbench v1.1; tam pievienota saite uz Studio.
- `MI_darbnica_maklerei_1_1.html` paliek neskarta.
- `property-valuation-studio/` ir jaunā Property Valuation Studio v1.0.
- Abas lietotnes darbojas pārlūkā un nesūta ievadītos datus ārējiem servisiem.
- Studio projektus glabā pārlūka lokālajā krātuvē. JSON eksports/imports paredzēts rezerves kopijai un pārcelšanai uz citu datoru.

GitHub Pages var ieslēgt, izvēloties `main` zaru un mapes sakni (`/`).
